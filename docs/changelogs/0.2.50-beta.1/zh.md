## v0.2.50-beta.1

### 修复
- 隐藏主窗口时按快捷键要「按好几次才开始录、还会漏掉开头几个字」的问题：现在按下快捷键的瞬间就开始录音，不再等界面唤醒。
- 录音偶发卡住关不掉：托盘菜单在录音时新增「停止录音」，任何时候都能一键结束。
- 录入组合快捷键并保存时偶发整个程序卡死。

### 改进
- 当听写快捷键用了 Fn 键、而 macOS「按下 🌐 键时」被设成了切换输入法 / Emoji / 听写时，设置里会提示你改成「不执行任何操作」，避免按键被系统吃掉导致录音停不下来。

### 已知问题
- 本版为灰度 beta：采集时机改动较大，如遇录音异常（麦克风指示灯不灭、录音无声）请反馈。
