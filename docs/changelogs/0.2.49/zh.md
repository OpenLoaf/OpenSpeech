## v0.2.49

### 新增
- 会议录制支持暂停 / 继续：暂停后可随时接着录，转写自动续接
- 会议双语翻译：开启后边录边译，可选翻译目标语言
- 会议记录支持加入收藏、重命名标题、生成 AI 摘要
- 支持超过 5 分钟的长录音转写：以前录太长会被直接拒绝，现在按时长自动走长音频转写，等待时间也相应放宽
- 再次打开 OpenSpeech 时会聚焦已运行的窗口，不再重复启动

### 改进
- 后台 / 主窗失焦时听写更稳：语音识别和 AI 整理改到后端一次跑完，不再因为窗口在后台被系统节流而卡顿、延迟或丢字
- 积分不足时（无论是 AI 整理还是听写阶段）现在都会明确提示「积分余额不足」，不再显示成笼统的服务错误
- 会议相关错误提示更清晰：麦克风被占用、启动 / 暂停 / 继续失败、历史读写失败都给出可操作建议，并提供「上报错误」入口
- 一次性操作提示（toast）不再在主窗里无限堆叠，最多同时显示 3 条，界面更清爽
- 设置项下拉框样式全应用统一
- 默认关闭「复制到剪贴板」

### 修复
- 修复偶发「录音刚开始就立刻被取消」（伴随一声提示音、浮窗一闪而过）的问题，多见于用 🌐 / Fn 键作为快捷键、且期间切换输入法时
- 修复「先按快捷键开始录音、再切到另一个 app（如微信）的输入框」时整理好的文字没自动填入、只弹结果面板的问题
- 在一行文字中间补字时精确插入光标处，不再往前 / 往后跳一格（此前中文输入法下高概率错位）
- 听写结果偶发重复标点（如「，，」）现在会自动合并，历史记录里的原始文本也保持干净
- 连续快速听写时前一段偶发「说到一半浮窗就消失、没填进输入框」：现在每段完整转写填入后再接下一段
- 修复 Windows 上偶发「一直卡在转录中」、需重启才能继续听写的问题
- 全局快捷键偶发「假死」（按了没反应、要重启才恢复）：改为串行注册根治

### 已知问题
