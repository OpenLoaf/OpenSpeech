## v0.2.52

针对 0.2.51 发布后当天的两条「听写结果对不上」反馈做的紧急修复。

### 修复
- 修复口述一个还没想好细节的请求（比如「帮我用 Cloudflare 的命令加一个 DNS 设置」）时，AI 整理会自作主张「补全」成带具体域名、记录类型、IP 的版本（example.com / 类型 A / 1.2.3.4 全是编的）。现在这类模糊请求只做口语清理，不会替你添任何参数。
- 修复词典里英文词条较多时，「AI 整理结果被整段换成之前某条历史内容」的兜底失效：之前的兜底把词典里所有字母都当成「你说过的」，导致含英文的错误输出漏网。现在只对真正命中词典的整词放行，抄历史（哪怕掐头去尾）也能被识别并回退到识别原文。
