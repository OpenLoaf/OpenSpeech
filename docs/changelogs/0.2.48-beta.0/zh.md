## v0.2.48-beta.0

> 本版本以 beta 形式发布，beta 用户会自动收到更新，stable 用户继续停在
> 0.2.47——OpenSpeech 设置 → 关于 → 更新通道里切「Beta」可加入。

### 修复

- **快捷键偶尔呼不出，要退出重进**：启动期间快捷键注册和「按住即触发」的状态
  初始化存在 race——某些时序下 PTT / 翻译两条按住键会被静默跳过、整次会话
  按了没反应。本版把状态初始化提到 builder 阶段，确保任何时序下前端 invoke
  都能拿到状态。重启即可恢复的老 bug 这次根治。
- **会议直连模式 SaaS 401 失败**：会议模块走 SaaS 直连时缺 token 续期机制，
  token 过期后整段会议失败。补 token 预检 + 401 续期一次重试。
- **ASR 把字母+数字代号拆成两段（"A 八" / "pin 七"）**：prompt 里 r3 谐音
  修复段对「单字母 + 独立数字词 = 一个 alphanumeric code」这种形态缺
  显式信号，加锚点示例修复。

### 改进

- **overlay 录音条 transcribing 阶段加两个兜底按钮**：
  - **✗ 保留**：保留音频 + 已转录的 raw 文字写历史（status=cancelled），立即
    切回 idle，不再把内容 paste 到光标。
  - **✓ 跳过 AI 优化**：跳过 AI refine，raw 文字写历史（status=success）+
    自动写剪贴板 + 显示到 overlay 兜底面板供复制，不再 paste 到光标。
  - 用于「ASR 出来已经够用、不想再走 refine 那 1-2 秒」或「想保留原话不想被
    refine 改」的场景。
- **dictation 录音期间软暂停升级检查**：开始听写后停下 updater 的周期检查，
  避免下载流量挤占网络让 ASR / refine RTT 抖动；停录后恢复。

### 已知问题

- 极少数情况下，模型在很复杂的输入（如 7 点中间跳了 1 点的工程整改单 + 历史
  邮件 context）上会把内心思考过程当输出吐出来（"自我修正 / 让我们再看一遍
  / 决定:" 等独白被直接 paste 到光标位置）。无稳定复现路径，本版未修。
