## v0.2.51

本版合并 0.2.51-beta.0 / beta.1 两轮灰度内容转正，并修复 beta 期间反馈的「听写结果被改成无关内容」问题。

### 修复
- 修复听写结果偶尔「跟说的完全是两回事」：AI 整理有概率把系统时间当成你说的话填进去（比如「下午的行程是点点点」变成「上午九点十五分」），或者抄一段之前听写过的历史内容、只留下开头两个字。现在这类明显对不上的输出会被自动丢弃，直接给出识别原文，也不会再污染后续几次听写。
- 口述「点点点」「三个点」这类省略号占位时，AI 整理只写成「……」，不再凭空补一个具体内容。
- 修复只说一个很短的词（比如单个英文单词，或语速较快的中文双字词）时，偶尔会提示「没有检测到人声」、听写没有任何输出的问题。
- 会议结束时立即保存历史记录，降低前端异常或窗口被关闭后整场会议记录丢失的概率；取消会议不再留下半条记录，重复保存不会产生重复记录。
- 修复切换页面后会议字幕订阅丢失的问题。
- 麦克风被拔掉、被其他程序独占或系统中断录音时，提示信息会明确说明原因，而不是笼统的「录音失败」。
- 修复 Windows 高缩放比例（如 175%）下启动窗口高于工作区、底部被任务栏遮住的问题；任务栏停靠在左侧 / 上方时窗口也能正确居中。

### 改进
- 双语翻译默认优先显示译文，并支持在设置中切换「译文在上」或「原文在上」。
