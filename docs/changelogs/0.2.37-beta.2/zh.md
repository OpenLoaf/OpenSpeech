## v0.2.37-beta.2

### 修复
- 多屏 + 混合 DPI 下，悬浮条不再卡在主屏：现在跟随你当前输入焦点所在
  的那块屏，无论是按快捷键唤起还是切应用，悬浮条都会跟过去。同屏切换
  不抖动。
- macOS 上把悬浮条抬离 Dock 顶 16pt，pill 视觉上不再被 Dock 挤兑。

### 改进
- Beta 包的本机日志档位提升到 Debug：发 beta 反馈时可以附更完整的诊断
  信息，方便我们排查；正式版仍保持 Info，不会在终端用户机器堆噪声。

### 已知问题
- 历史记录的"反馈本条"入口仍在开发中（本轮已铺好后端通路，前端 UI
  下一版接入）。
- 无线麦克风功能仍未开放 UI，沿袭前几版状态，仅供内部测试。
