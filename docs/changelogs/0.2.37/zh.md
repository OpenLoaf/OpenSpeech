## v0.2.37

这一版以稳定性为主，集中修了快捷键、悬浮条和录音相关的一批老问题。

### 修复

- **快捷键空闲后失灵**：长时间没用之后第一次按快捷键，前几次事件会被
  丢、之后又一次性堆过来导致状态机乱跳。这版把 overlay 显示改成异步
  调度，不再阻塞快捷键投递，按下即响应。
- **快捷键没声音 / 一直没声音**：底层音频设备启动竞争失败时自动重试
  一次；录音状态机如果未正常复位，30 秒后会自动清除，不会再出现
  "按完一次后所有后续提示音静默"。设置页新增「测试提示音」按钮，可
  一键诊断当前音频状态并强制试播一声。
- **长录音 (>30 秒) 结束时多一声提示音**：之前长录音结束后再按一下
  PTT / toggle，会先播 start 再播 stop（两声）。这版修了，长录音
  也只有一声 stop。
- **多屏 + 混合 DPI 下悬浮条卡在主屏**：现在悬浮条跟随你当前输入
  焦点所在的那块屏幕，按快捷键、切应用都跟过去；同屏切换不抖动。
- **macOS 悬浮条被 Dock 挤兑**：把 pill 抬离 Dock 顶 16pt，视觉
  位置更稳。
- **macOS 录完音麦克风指示器（橙点）不熄**：之前录完一次音，状态栏
  右上角的橙点有时不熄灭，好像 OpenSpeech 一直在偷听——其实没在录，
  只是麦克风句柄没正确释放。这版彻底修了：录完即释放，indicator
  立刻消失。中途切换设备（AirPods 自动接管 / 蓝牙耳机休眠后切回内置
  麦）也不会再卡住。

### 改进

- **AI 整理不再无脑加尾句号**。默认在你原话本身没带句号时自动去掉
  AI 多补的「。/. /．」尾标点；可在高级里切到「永远去掉」或「保留」
  两个模式。
- **字典代理对"反复纠正"更敏感**：如果你在最近的历史里反复把同一个
  错听改成同一个正确写法（≥2 次且读音接近），现在会强制入库为新词
  条，不再因为保守判断而漏掉。
