## v0.2.55

### 修复
- **Windows 上快捷键更好按了**：之前快速按下 Alt + Win 这类组合键经常没反应，要按住一会儿才触发。现在按下即触发，快按也不会漏。

### 改进
- **Windows 翻译快捷键默认改为「右 Alt + 右 Win」**：和听写的「左 Alt + 左 Win」左右对称，更好记；快捷键显示也会标出左 / 右。
  - 从没改过快捷键的用户升级后会自动换成新组合；改过任意快捷键的用户保持原设置不变。
  - 部分笔记本和紧凑键盘没有右 Win 键，这种情况请在「设置 → 快捷键」里把翻译改回「右 Ctrl」或其他组合。
- **窗口较窄时页面更舒展**：各页面两侧留白收窄，小窗口下能显示更多内容。
