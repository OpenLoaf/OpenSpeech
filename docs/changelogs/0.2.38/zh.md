## v0.2.38

这一版以会议功能为主，把"长会议中途强退就丢内容"的老问题彻底
解决，同时修了一个绕了很久的提示音失声问题。

### 新增

- **会议录音崩溃也能找回**：会议现在边录边把音频和字幕分别写进
  本地 `.ogg` 和 `.jsonl` 文件，不再像以前那样靠内存累积——
  webview 崩溃、强退 OpenSpeech、笔记本断电，前面已经识别出来
  的内容都不会丢。重新打开 OpenSpeech 会自动扫描这些"孤儿"
  录音，在历史记录里以「自动恢复」标记呈现。

### 修复

- **跑久了之后没有按键提示音**：之前 OpenSpeech 开着一两个小时
  之后，按快捷键悬浮条还在但「叮咚」声没了；切到蓝牙耳机 /
  AirPlay 之后也会出现这种静默。底层是 macOS 系统会偷偷把
  长时间没出声的音频通道暂停，新版本会自动重连，按下立刻有声。
- **macOS 中文输入法下流式输入被吞字**：开着注音 / 拼音 / 仓颉 /
  鼠须管 / 搜狗等输入法时，流式注入会被输入法当成正在组字，
  最终敲出来的内容缺字。这版会自动检测当前是不是这类输入法，
  是的话改用整段粘贴，输入完整可靠。

### 改进

- **AI 整理对列表的处理更自然**：口头说出来的「第一、第二、第三」
  会自动转成无序列表的纯文本，不再硬塞 1. 2. 3.；在终端 / 编辑器
  里整理代码片段时会跳过列表化、保留原样。
- **字典代理对反复纠正更敏感**：你在最近的历史里反复把同一个错听
  改成同一个正确写法（≥ 2 次且读音接近），现在会更主动入库为新
  词条。
- **会议字幕长列表更流畅**：长达 1–2 小时的会议字幕列表换成虚拟
  滚动，滚动和切换不再卡顿。
- **历史记录可单条反馈**：在每条历史的菜单里新增「反馈本条」入口，
  把错听 / AI 整理错误的样本直接发回给我们改 prompt 用。
