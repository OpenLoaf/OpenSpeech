## v0.2.39

这一版主要解决了会议录制字幕在开始几秒就消失的问题，修了中文输入法
打到一半时粘贴内容丢失的体验问题，并为后续会议成本分析打好数据基础。

### 修复

- **会议录制实时字幕在开始几秒后消失**：会议启动约 5 秒后，腾讯 ASR
  服务会因为客户端发送音频分片过于密集（默认 ~96 个/秒，腾讯上限 25 个/秒）
  触发限频，整段 WebSocket 会话被立即终止，字幕区停在「正在聆听...」、
  会议结束后逐字稿是空的。本版在会话内把音频聚合为 200ms 一包再发，
  发送频率稳定在 5 个/秒，不再触发限频。

- **macOS / Windows 输入法在候选词阶段粘贴失败**：注音、拼音、仓颉、
  Windows 三方输入法等在拼字（候选词高亮）时，Cmd/Ctrl+V 会被 IME 吃掉，
  导致粘贴指令被忽略且当前候选残留在编辑区。本版在执行粘贴前先发一次
  右方向键让 IME 把候选 commit 掉再粘贴，副作用比 Esc（丢字）和
  Return（误发消息）都更小。

### 改进

- **日志按版本自动切档**：每次升级（或回滚到不同版本）后启动，
  之前的 OpenSpeech.log 会被自动归档，新版本从空白日志文件开始写，
  方便排查升级前后的问题不互相干扰。归档文件 7 天后自动清理。

### 内部（UI 暂未开放）

- **会议 credits 消耗拆分为 ASR 和 AI 优化两列**：可区分「转写本身贵」
  还是「AI 整理贵」，以后做成本透视时直接能看。老会议不补，新会议起记录。
- **会议 history 新增 title 与 speaker_names 字段**：为后续「AI 自动生成
  会议标题」和「review 视图改 speaker 名」做 schema 准备，本版 UI 未开放。
