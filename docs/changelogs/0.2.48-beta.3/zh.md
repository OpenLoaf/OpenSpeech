## v0.2.48-beta.3

字典 + 领域两个体验改造：让自定义词典从「一条一条手敲」变成「粘贴一段文本 AI 帮你挑」，让 AI 优化的领域设定从「只能在 14 个内置里选」变成「自己造一个」。

### 新增

- **字典批量抽词（AI 一次性建库）**：词典页右上角多了「+ 批量」按钮，粘贴任意文本（你写的术语清单、看到的中英对照、一段技术文章、会议纪要都行），AI 自动挑出值得入库的专有名词 / 项目名 / 行业术语 / 缩写，每条附带建议入库的理由，你勾选后批量入库。
  - 中英对照（如「船首 bow / head」）会自动拆成中文一条 + 英文一条，互填为 aliases，保证你说中文 / 说英文都能命中。
  - 跳过日常常用词与已在字典里的条目（标记「已有」、默认不勾选）。
  - 单次输入 ≤ 12,000 字，超长自动截断；单次最多 100 条建议。
- **自定义领域**：以前 AI 优化的领域只能从我们内置的 14 个（编程 / 法律 / 医学等）里选，现在你可以在词典页底部「自定义领域」自建领域，自取名字 + 自填关键词。
  - 总数上限 20 个；单领域关键词 ≤ 30 条，每条 ≤ 40 字符；领域名 ≤ 24 字符。
  - 自定义领域跟内置领域一样可以勾选进 AI 优化提示词的 `<Domains>` 头，最多同时选 3 个。
- **新增内置「海事 / 航海」领域**：内置 IMO / SOLAS / MARPOL / ECDIS / AIS / GMDSS / EPIRB / DWT / TEU / FPSO / Ro-Ro / B/L / ETA / knot / starboard 等海事术语，搞航运 / 船舶 / 港口 / 海事法律相关的可以直接勾选。

### 内部

- 字典设置 schema 升级到 v18（向前兼容，旧数据自动迁移补 `customDomains: []`）。
- ASR 引导提示词微调（短文混杂场景识别更稳）。

### 已知风险

- 批量抽词需要 OpenLoaf SaaS 在线，未登录 / 离线会失败（弹 toast，不影响正常使用字典）。
- 自定义领域目前**不跨设备同步**（本地存储），与字典本身保持一致。
