## v0.2.39-beta.0

这是一次 beta 重发版，相对 0.2.38 stable **没有新功能或代码改动**——只是把
Cargo.lock 同步补齐，作为后续修复的干净基线。

发这版的目的：

- 让仍在 0.2.37-beta 的 beta 通道用户升到当前的代码基线，方便后续按 beta 流程
  快速迭代修复。
- 给排查中的「0.2.38 stable 会议录制不显示实时内容」问题准备一个可对照的 beta
  起点。

### 已知问题

- **0.2.38 stable 上发现的会议实时识别问题，本 beta 同样存在**：
  会议开始后 5 秒左右 SaaS WebSocket 会被服务端主动关闭，导致字幕区不显示任何
  内容。0.2.37-beta.3 / 0.2.37 stable 上不会出现，根因正在排查中，下一个
  beta 会给出修复。
- 无线麦克风功能 UI 仍未开放，沿袭前几版状态，仅供内部测试。
