## v0.2.48

beta 周期里收口的一版正式发布，合并 beta.0 → beta.3 的全部内容，并补两项面向用户体验的小调整。

### 新增

- **字典批量抽词（AI 一次性建库）**：词典页右上角多了「+ 批量」按钮，粘贴任意文本（术语清单、中英对照、技术文章、会议纪要都行），AI 自动挑出值得入库的专有名词 / 项目名 / 行业术语 / 缩写，每条附带建议入库的理由，勾选后批量入库。
  - 中英对照（如「船首 bow / head」）自动拆成中文 + 英文两条互填 aliases，说哪种都能命中。
  - 跳过日常常用词与字典里已有的条目（标记「已有」、默认不勾选）。
  - 单次输入 ≤ 12,000 字，最多 100 条建议。
- **自定义领域**：AI 优化的领域不再只能从内置 14 个里选，词典页底部「自定义领域」可以自建。
  - 总数上限 20 个；单领域关键词 ≤ 30 条、每条 ≤ 40 字符；领域名 ≤ 24 字符。
  - 跟内置领域一样可勾进 AI 优化提示词的 `<Domains>` 头，最多同时选 3 个。
- **新增内置「海事 / 航海」领域**：覆盖 IMO / SOLAS / MARPOL / ECDIS / AIS / GMDSS / EPIRB / DWT / TEU / FPSO / Ro-Ro / B/L / ETA / knot / starboard 等海事术语，搞航运 / 船舶 / 港口 / 海事法律相关的直接勾选即可。
- **麦克风启动失败 → 弹明确提示**：以前按 PTT 麦克风用不了，UI 静悄悄没反应。现在一旦后端起 audio 失败，悬浮条立即弹 toast，按失败原因分 6 类给指引：
  - 权限被拒 → 指引「系统设置 → 隐私与安全性 → 麦克风」开启
  - 设备被其它应用独占 → 指引「右上角控制中心 → 麦克风」查看占用方
  - 设备拔出（USB / 蓝牙麦克风断开）→ 提示重新连接
  - 没找到麦克风 / 配置不被支持 / 其它通用错误也各有对应文案
- **静音兜底提示**：按 PTT 3 秒后如果完全没拾到声音，悬浮条加一条「似乎没拾到声音」warning，提示麦克风可能被遮挡 / 被其它应用独占 / 音量太低。不打断录音，由用户判断。

### 改进

- **悬浮条录音条 transcribing 阶段加两个兜底按钮**：
  - **✗ 保留**：保留音频 + 已转录的 raw 文字写历史（状态=已取消），立即切回 idle，不再 paste 到光标。
  - **✓ 跳过 AI 优化**：跳过 AI refine，raw 文字写历史（状态=成功）+ 自动写剪贴板 + 显示到悬浮条兜底面板，不再 paste 到光标。
  - 适合「ASR 出来已经够用、不想再多等 1-2 秒 refine」或「想保留原话不想被 refine 改」的场景。
- **听写期间软暂停升级检查**：开始录音后停掉 updater 的周期检查，避免下载流量挤占网络让 ASR / refine 延迟抖动；停录后恢复。
- **默认开启「开机启动」**：dictation 类工具的核心价值是「随时按下就能用」，新装用户默认常驻、更符合预期。老用户的现有设置不受影响。
- **Windows 工具箱快捷键改 `Ctrl + Alt + T`**：原默认 `Shift + Win + T` 与 PowerToys `Win+Shift+*` 系列、任务栏 `Win+T` 衍生组合频繁冲突，全局快捷键直接注册失败。新默认在系统层与 PowerToys 都干净。macOS / Linux 维持原快捷键不变。

### 修复

- **快捷键偶尔呼不出、要退出重进**：启动期间快捷键注册和「按住即触发」的状态初始化存在 race，某些时序下 PTT / 翻译两条按住键会被静默跳过、整次会话按了没反应。本版把状态初始化提到 builder 阶段，根治。
- **退出 OpenSpeech 后 macOS 状态栏麦克风指示灯不熄灭**：主窗口关闭（红叉 / Cmd+W / 托盘隐藏 / `Shift+Cmd+O` toggle 收起）走的是 hide-to-tray，进程仍在后台运行；但 hide-to-tray 路径完全没释放 audio stream，只要前一轮录音的引用计数有任何漏减（PTT 被中断、webview reload、stt 错误路径未平衡），cpal stream 就一直活、macOS 橙色 mic 指示灯就一直钉亮。本版在 hide-to-tray 末尾强制 release audio，主窗一收起 indicator 就熄。
- **悬浮条后台状态机停摆**：主窗 hide 后悬浮条永远是 unfocused 窗口，macOS WebKit 默认会 throttle 它的 JS 事件循环，导致录音中 / transcribing / refining 切换在后台时迟迟不更新。本版禁用 overlay 与主窗的 background throttling，状态机后台也准时跟上。
- **会议直连模式 SaaS 401 失败**：会议模块走 SaaS 直连时缺 token 续期机制，token 过期后整段会议失败。补 token 预检 + 401 续期一次重试。
- **ASR 把字母+数字代号拆成两段（"A 八" / "pin 七"）**：prompt 里谐音段对「单字母 + 独立数字词 = 一个 alphanumeric code」这种形态缺显式信号，加锚点示例修复。

### 已知问题

- 极少数情况下，模型在很复杂的输入（如 7 点中间跳了 1 点的工程整改单 + 历史邮件 context）上会把内心思考过程当输出吐出来（"自我修正 / 让我们再看一遍 / 决定:" 等独白被直接 paste 到光标位置）。无稳定复现路径，本版未修。
- 批量抽词与会议直连需要 OpenLoaf SaaS 在线，未登录 / 离线会失败（弹 toast，不影响字典 / 听写正常使用）。
- 自定义领域目前不跨设备同步（本地存储），与字典本身保持一致。
