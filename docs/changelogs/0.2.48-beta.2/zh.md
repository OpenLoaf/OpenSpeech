## v0.2.48-beta.2

继续 beta.1 后的 hotfix——这次加的是"麦克风出问题时给用户一个看得懂的提示"。

### 新增

- **麦克风启动失败 → 弹明确提示**：以前按 PTT 如果麦克风用不了，UI 就静悄悄
  没反应，要看日志才知道为什么。现在按 PTT 一旦后端起 audio 失败，会立即在
  悬浮条上弹 toast，按失败原因分 6 类给出不同指引：
  - 麦克风权限被拒 → 指引「系统设置 → 隐私与安全性 → 麦克风」开启
  - 设备被其它应用独占 → 指引「右上角控制中心 → 麦克风」查看占用方
  - 设备拔出（USB / 蓝牙麦克风断开）→ 提示重新连接
  - 没找到麦克风 / 配置不被支持 / 其它通用错误也各有对应文案
- **静音兜底提示**：按 PTT 3 秒后如果完全没拾到声音，悬浮条加一条「似乎没拾
  到声音」warning toast，提示麦克风可能被遮挡 / 被其它应用独占 / 音量太低。
  不打断录音，由用户判断是不是真没说话。

### 修复（继承 beta.1）

- hide-to-tray 不释放 audio stream 导致 macOS 状态栏麦克风指示灯钉亮（详见
  beta.1 changelog）。
