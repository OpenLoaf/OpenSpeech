## v0.2.39-beta.2

这一版主要修了「中文输入法打到一半切换 OpenSpeech 粘贴时整段被吞掉」的体验
问题，同时为后续做会议成本透视 + 会议手工修订 UI 打了数据基础。

### 修复

- **macOS 注音 / 拼音 / 仓颉、Windows 三方输入法在 composition 进行中粘贴失败**：
  IME 在拼字（候选词高亮）阶段会吃掉所有按键事件，包括 Cmd/Ctrl+V，导致
  粘贴指令被忽略 + 当前候选残留在编辑区像「全选」一样。本版在执行粘贴前先
  发一次「右方向键」让 IME 把候选 commit 掉再粘贴，副作用比 Esc（丢字）和
  Return（误发消息）都小。

### 新增（内部能力，UI 暂未开放）

- **会议消耗的 OpenLoaf SaaS credits 现在分 ASR / AI 优化两列记录**：以后
  能直接看出某段会议是「转写本身贵」还是「AI 概括 / 整理贵」，便于自检。
  老记录不补，新会议起开始记录。
- **会议条目新增 title 与 speaker_names 两个字段**：title 留给后续做「AI
  自动概括的会议名」（≤ 15 字），speaker_names 留给后续做「review 视图里
  双击改 speaker 名」。本版只建数据库列，UI 还没开放。

### 已知问题

- 上面新增的两块「内部能力」只是把数据库 schema 准备好，前端 UI 尚未对外
  开放，需等下一两个 beta。
- 无线麦克风功能 UI 仍未开放，沿袭前几版状态，仅供内部测试。
