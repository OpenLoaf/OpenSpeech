## v0.2.53

### 改进
- **语音识别换到新一代模型，专有名词认得更准**：云端听写升级到通义千问新一代语音识别模型。你在词典里添加的词会作为真正的「热词」交给识别模型，而不只是一段参考提示。
  - 用你过去手动改过的 20 条真实录音做对比，专有名词和术语认对的数量从 8 个提升到 13 个（总共 14 个）。
  - 中文同音词：负荷跟踪、晶振、烧录、烧写等更少写错。
  - 口述的英文缩写：CLI、JST、context7 等不再被拆成一个个字母。
  - 识别速度也略快一些，积分消耗不变。
- **实时字幕模式也支持词典**：边说边出字的实时模式现在也会用上你的词典和最近几条听写内容来提高识别准确率。注意：边说边显示的临时文字仍可能有同音字，停顿后给出的最终文字才会按词典修正。
- **设置页新增「系统设置」按钮**：「输入声音」一行的电平表旁边新增一个按钮，点一下直接打开系统的声音设置（macOS / Windows / Linux 均支持），发现输入电平不对时可以直接去切换输入设备或调整音量。

### 小提示
- 想让某个词识别得更准，把它**正确的写法**加进词典就行。
